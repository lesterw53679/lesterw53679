# Lester J. Williams

Professional geologist, groundwater hydrologist, and Python developer.

I build practical tools that bring geological data, scientific methods, and software together to support water-resource management, hydrogeologic assessment, and collaborative problem solving.

## Logic Cloud Geo

I am the founder and sole programmer behind **Logic Cloud Geo (LCG)**, an independent geoscience software and consulting initiative with free public demonstration tools.

[Explore the live applications](https://logiccloudgeo.com) · [Visit the LCG GitHub organization](https://github.com/logiccloudgeo)

## Current work

| Project | Purpose |
| --- | --- |
| [Geological framework and subsurface services](https://logiccloudgeo.com/subsurface/) | Make published framework information useful through interactive maps, location-based queries, and documented scientific methods. The Floridan Aquifer System is the current reference example. [USGS Professional Paper 1807](https://pubs.usgs.gov/pp/1807/) · [AGOL map collection](https://logiccloudgeo.com/arcgis-maps/). |

## Consulting and collaboration

My focus includes water-resource management, hydrogeologic assessments, scientific data preparation, custom applications, and staff training. I am especially interested in helping agencies and other organizations extract useful insight from their data and build tools their own staff can maintain.

The planned delivery model includes deployment into client-owned cloud environments, documentation, and training, with ongoing support defined separately. Azure is the current reference environment.

I welcome conversations about scoped projects and future collaboration in geoscience, hydrogeology, Python, GIS, and scientific web services.
